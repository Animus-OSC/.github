# Support

Animus maintains multiple products, tools and research projects with different release boundaries. For technical usage questions, begin with the target repository's README, documentation, release notes and issue/discussion templates.

- **Public SDK questions:** use the documented support channels in [Animus DataLab Python SDK](https://github.com/Animus-OSC/animus-datalab-sdk).
- **Bugs and feature requests:** use the target repository's issue tracker if it is enabled, and include version information and a minimal reproduction.
- **Security vulnerabilities:** do not report publicly; follow the relevant repository's security policy or [organization guidance](SECURITY.md).
- **Business or product inquiries:** use the verified contact channel published on [kapakka.org](https://kapakka.org).

Private repositories, prototypes and research concepts are not publicly supported merely because they are mentioned on the organization profile. No service-level commitment is implied by this document.
